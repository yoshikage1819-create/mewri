# Mewri に参加してくれるあなたへ

これは、技術的な手伝いをお願いする文章ではありません。

コードを書いてほしいわけでも、データベースやセキュリティを見てほしいわけでもありません。
むしろ、そこは触らなくて大丈夫です。

お願いしたいのは、もっと人間っぽいことです。

Mewri を一緒に育てる仲間として、あなたの「これ、なんかいい」「ここは冷たい」「ここはわかりにくい」「これは誰かに見せたくなる」という感覚を貸してほしいです。

## まず伝えたいこと

Mewri は、ひとりで黙々と作るだけのソフトウェアにしたくありません。

友達と、面白いことをしながら生きていくためのプロジェクトにしたいです。
ただ便利なアプリを作るというより、これからの生活の中に、少しずつワクワクする方向や、誰かと一緒に作っている感じを増やしていきたいです。

だから、あなたに求めているのは専門知識ではありません。

必要なのは、あなたの感覚です。

## Mewri がある理由

今のSNSは、便利だけど、少し冷たく感じることがあります。

誰かの投稿を眺めて、反応して、流れてくるものを消費しているうちに、自分の気持ちをちゃんと出す場所が少なくなっていく感じがあります。

本当はもっと、うまく言葉にならない気分や、日々の小さな発見や、友達とだけ共有したい空気があるはずです。

Mewri は、そういうものをもう少し自由に、あたたかく出せる場所にしたいです。

写真を投稿するだけの場所ではなく、友達と一緒にテーマを見て、写真を残して、あとからZINEのように読み返せる場所。

その体験を通して、関係性にもう少し温度が戻るような場所を目指しています。

## 今のSNSに感じている違和感

今のSNSでは、気づかないうちに受け身になりやすいです。

おすすめされたものを見る。
反応が多いものを見る。
ランキングやアルゴリズムに合わせて、自分の表現の形が変わっていく。

その中で、本当は出したかった素直な気持ちが、少しずつ出しにくくなることがあります。

人とのつながりも、数字や反応の形に寄りすぎると、どこか人工的で、浅くて、冷たいものに感じることがあります。

Mewri は、その反対側に行きたいです。

もっと小さくて、近くて、ちゃんと人の気配がある場所を作りたいです。

## Mewri がなりたいもの

Mewri は、感情をもっと自由に表現できる場所になりたいです。

きれいに整った投稿だけではなく、少し曖昧な気分や、言葉にしきれない感覚も置ける場所。

誰かの反応が、ただの数字ではなく、「ちゃんと見てくれた」「一緒に感じてくれた」と思える場所。

友達と一緒に、空気、言葉、テーマ、写真、ZINE、コミュニティの感じを育てていける場所。

Mewri は、アプリである前に、そういう創作の方向性でありたいです。

## あなたの感覚が必要な理由

技術のことは、わからなくて大丈夫です。

ここで大事なのは、むしろ技術に詳しくないからこそ見えることです。

たとえば、こういう反応が必要です。

- これはワクワクする
- これは少し冷たい
- これは意味がわからない
- これは生きている感じがする
- これは友達を誘いたくなる
- これは説明されてもピンとこない
- この言葉はMewriっぽい
- この空気はMewriっぽくない

ひとりで作っていると、方向が少しずれても気づきにくくなります。

ひとりの好みだけで進むと、世界が固まりすぎることがあります。

あなたの子どもっぽいワクワク、好奇心、正直な違和感、言葉になる前の感覚があることで、Mewri はもっと柔らかく、あたたかく、生きたプロジェクトになれます。

## 手伝ってほしいこと

難しいことはしなくて大丈夫です。

最初にお願いしたいのは、実際に触って、見て、感じたことをそのまま返してもらうことです。

たとえば、こういうことを手伝ってほしいです。

- ローカルデモを触ってみる
- どの画面で迷ったかを教える
- どの言葉が冷たく感じたかを教える
- どの言葉があたたかく感じたかを教える
- 全体の雰囲気に正直に反応する
- テーマ案、ZINE案、言葉の案を出す
- 友達を誘いたくなる瞬間を一緒に考える
- 方向がずれていると感じたら言う
- 「ここは残したい」という感覚をメモする
- Mewri がワクワクし続けるように見張る

正解を出す必要はありません。

むしろ、正直な第一印象のほうが大事です。

## やらなくていいこと

あなたに技術的な責任はありません。

次のことは、やらなくて大丈夫です。

- コードを書くこと
- セキュリティを確認すること
- データベースを触ること
- 本番公開やデプロイを判断すること
- ログインや認証の仕組みを考えること
- API、Storage、Supabase などを理解すること
- 技術的に正しいかどうかを判断すること

技術の判断は、こちらで止めて確認します。

あなたには、体験の温度、言葉の感じ、関係性の気配を見てほしいです。

## 入力しない・触らないもの

安全のために、次のものは入力しないでください。

- 本物のパスワード
- 自分や他人の個人情報
- 非公開の参加者情報
- トークン
- APIキー
- magic link
- secret URL
- 招待リンクや管理用リンクらしきもの

また、次のものは触らないでください。

- production
- deploy
- backend
- auth
- database
- storage
- Supabaseの設定
- RLSやStorage policy
- 環境変数
- 秘密鍵

もし画面や説明の中で、よくわからない入力欄や危なそうな言葉が出てきたら、そこで止まってください。

その場で判断しなくて大丈夫です。

## 今日やってほしいこと

最初の日は、これだけで十分です。

1. この文章を読む
2. もしデモが共有されたら、軽く触ってみる
3. 途中で迷ったところをメモする
4. 「いい」「冷たい」「わからない」「もう一回見たい」を正直に書く
5. 下のフィードバックテンプレートに答える
6. そのまま手動で送る

きれいにまとめなくて大丈夫です。

短い言葉でも、箇条書きでも、途中で止まった感想でも大丈夫です。

```text
6. 誰かを誘いたいと思ったところは？

8. 逆に、Mewriが失ってはいけないものは？

```

## 毎週の関わり方

毎週、30分から60分くらいで大丈夫です。

無理に長く関わるより、短くても続けて、感覚を共有し続けるほうが大事です。

おすすめの流れはこれです。

1. 今のデモやメモを見る
2. 感じたことをそのまま話す
3. 迷ったところ、冷たかったところ、よかったところを出す
4. 次に直すことを1つから3つ選ぶ
5. 「これは失いたくない」という感覚を残す

Mewri にとって、その「失いたくない感じ」はかなり大事です。

機能が増えても、最初にあった温度を失ったら意味がありません。

## 最後に

Mewri は、ひとりで作り切るものではないと思っています。

ひとりで作ると、速く進むことはあります。
でも、温度や空気や、誰かと一緒に生きている感じは、ひとりでは作りにくいです。

あなたが参加してくれることで、Mewri はただの個人プロジェクトから、少しずつ生きた場所に変わっていきます。

技術を手伝ってほしいのではなく、一緒に面白がってほしいです。

一緒に、友達とワクワクしながら生きていくための場所を作っていきたいです。
