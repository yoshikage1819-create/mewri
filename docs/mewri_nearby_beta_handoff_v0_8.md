# Mewri 近距離βハンドオフ v0.8

作成日: 2026-05-22
状態: セルフチェック完了後の次ステップ

## 目的

このドキュメントは、セルフチェックが完了したあとに、近くの人へMewri v0.8を試してもらうための準備メモです。

ここでは新機能を追加しません。目的は、今のMVPが「初めて触る人」に伝わるかを確認することです。

## いま確認したいこと

近距離βで確認したいのは、機能の多さではありません。

確認することは次の4つです。

1. 最初に何をすればいいか分かるか。
2. 今日のテーマに投稿するルールが伝わるか。
3. `みんなの投稿` から `このZINEの中身` に行く流れが自然か。
4. `ZINEを生成` が、投稿が集まったあとの報酬として見えるか。

## テスターに渡す短い説明

テスターには、最初から詳しく説明しすぎないでください。

渡す説明はこれだけで十分です。

```text
今日のテーマに写真を投稿して、みんなの投稿で反映を確認し、ZINE生成まで試してください。
分かりにくい言葉や、次に何をすればいいか迷った場所があれば教えてください。
```

画面だけでどこまで伝わるかを見るため、横から細かく誘導しすぎないことが大事です。

## テスト前チェック

テスト前に確認すること:

- PCで `http://localhost:3000` が開ける。
- スマホで `http://192.168.1.11:3000` が開ける。
- PCとスマホが同じWi-Fiにつながっている。
- 赤いエラー画面が出ていない。
- `参加中のZINE` が最初の主要セクションとして見える。
- `このZINEの中身` に投稿一覧とZINE生成が分かれて見える。
- `フォロー中ユーザーの投稿` と `発見と回遊` が未実装枠に見える。

## テスト中に見ること

テスターが迷ったら、すぐに答えを教える前に、どこで止まったかを見てください。

見るポイント:

- `今日の投稿をする` を押せるか。
- 画像URL入力が難しい場合、サンプル画像ボタンを見つけられるか。
- 投稿後に `みんなの投稿` を押したくなるか。
- 投稿したものを `このZINEの中身` で見つけられるか。
- `ZINEを生成` が押せるようになる条件をなんとなく理解できるか。
- `ZINEを生成` が通常の補助ボタンより重要に見えるか。
- 未実装枠を実装済み機能だと勘違いしないか。

## テスト後に聞くこと

テストが終わったあと、次の質問をしてください。

```text
最初に何をすればいいか分かりましたか？
今日のテーマだけに投稿するルールは分かりましたか？
みんなの投稿は何を見る場所だと思いましたか？
このZINEの中身は、投稿一覧とZINE生成の場所として自然でしたか？
ZINEを生成したいと思いましたか？
未実装の場所は未実装だと分かりましたか？
友人にURLを送って試してもらうなら、何が足りないと思いましたか？
```

## 近距離βの合格条件

次の状態なら、v0.8は近距離βとして一旦合格です。

- テスターが投稿まで自力で進める。
- `みんなの投稿` の意味を大きく誤解しない。
- `このZINEの中身` が投稿一覧とZINE生成の場所だと伝わる。
- `ZINEを生成` が報酬として見える。
- 画面崩れや赤いエラーで止まらない。
- 未実装枠が実装済み機能に見えない。

## 合格しなかった場合

合格しなかった場合も、すぐにv0.9機能を入れないでください。

まずはv0.8の範囲で直します。

優先順位:

1. 文言の分かりにくさ。
2. ボタンの見つけにくさ。
3. 投稿一覧とZINE生成の距離感。
4. スマホ/PCの表示崩れ。

次の機能は、近距離βの結果を見てから判断します。

- `自分の投稿`
- hostが作るテーマ
- テーマなしで先に投稿する機能
- 複数グループへの投稿

## 次の判断

近距離βの後に、次のどれかを選びます。

1. テスターが迷わず使えた: URL共有βの準備に進む。
2. テスターが文言で迷った: v0.8のコピー修正に戻る。
3. テスターがテーマ外投稿を強く求めた: v0.9で `自分の投稿` を検討する。
4. テスターが人間主導のテーマを強く求めた: v0.9で hostテーマを検討する。
