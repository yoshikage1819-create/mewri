# Mewri セルフβテスト手順 v0.8

作成日: 2026-05-22
状態: 近くの人に見せる前の、自分用チェックリスト

## 目的

このドキュメントは、Mewri v0.8 を自分ひとりで確認するための手順です。

ここでやることは、新機能を作ることではありません。今あるMVPが、初めて触る人でも一通り使える状態になっているかを確認します。

特に見るポイントは次の3つです。

- 今日のテーマに投稿する流れが分かるか。
- `みんなの投稿` から投稿一覧を見られるか。
- 投稿が集まったあとに `ZINEを生成` したくなるか。

## 今の画面構成

ホーム画面は、次の順番になっているのが正しい状態です。

1. `参加中のZINE`
2. `このZINEの中身`
3. `フォロー中ユーザーの投稿`
4. `発見と回遊`

それぞれの役割は次の通りです。

- `参加中のZINE`: 今日のテーマを確認して、投稿する場所。
- `このZINEの中身`: みんなの投稿、終了したテーマ、3日サイクル、ZINE生成を見る場所。
- `フォロー中ユーザーの投稿`: まだ未実装の見本枠。
- `発見と回遊`: まだ未実装の見本枠。

## 大事な考え方

v0.8では、投稿とZINE生成を分けて考えます。

- 投稿は、すぐにできる小さな報酬。
- ZINE生成は、投稿が集まったあとに起きる大きな報酬。

そのため、`参加中のZINE` には投稿導線だけを置きます。`ZINEを生成` は `このZINEの中身` に置きます。

## テスト前の準備

1. PCで開発サーバーを起動します。

```powershell
npm.cmd run dev:host
```

2. PCで次のURLを開きます。

```text
http://localhost:3000
```

3. スマホをPCと同じWi-Fiにつなぎ、次のURLを開きます。

```text
http://192.168.1.11:3000
```

スマホで開けない場合は、先にPC側で `http://localhost:3000` が開けるか確認してください。

## セルフテスト手順

次の順番で、スマホとPCの両方を確認します。

1. ページを開く。
2. `参加中のZINE` が最初に見えるか確認する。
3. `今日のテーマ` が分かるか確認する。
4. `今日の投稿をする` を押す。
5. サンプル画像を使って投稿する。
6. キャプションを入力、または空のまま投稿してみる。
7. `みんなの投稿` を押す。
8. `このZINEの中身` に移動するか確認する。
9. 投稿した内容が表示されているか確認する。
10. 全体表示とテーマ別表示を切り替えてみる。
11. サンプル投稿を追加して、ZINE生成できる状態にする。
12. `ZINEを生成` が他のボタンより強く見えるか確認する。
13. `ZINEを生成` を押す。
14. 生成されたZINEのプレビューが出るか確認する。
15. リセットして、もう一度同じ流れを試す。

## 合格条件

次の条件を満たしていれば、近くの人に試してもらう準備ができています。

- スマホで画面が崩れていない。
- PCで画面が崩れていない。
- 赤いエラー画面が出ない。
- 投稿先が `今日のテーマ` に固定されている。
- 未来のテーマには投稿できない。
- 終了したテーマは見られるが、投稿先にはならない。
- `みんなの投稿` を押すと、参加中ZINEの投稿一覧に移動する。
- `このZINEの中身` が、投稿フォームではなく投稿一覧とZINE生成の場所に見える。
- `ZINEを生成` が、普通の補助ボタンより強い報酬に見える。
- `フォロー中ユーザーの投稿` と `発見と回遊` が、未実装の見本枠だと分かる。

## この段階で実装しないこと

セルフβテスト中に、次の機能は追加しません。

- hostが作るテーマ。
- `自分の投稿`。
- テーマなしで先に投稿する機能。
- 複数グループへの同時投稿。
- 本物のフォロー機能。
- 通知。
- 公開ディスカバリー。
- ログイン/認証。
- 共有データベース。
- 本物の画像アップロード。

これらが必要そうだと感じた場合は、すぐ実装せずに v0.9 の検討メモとして残します。


## テスト後の判断

セルフテストが終わったら、次のどれかを選びます。

1. 流れが分かりやすい場合: 近くの人に1回だけ試してもらう。
2. 流れが分かりにくい場合: v0.8の範囲で、文言やレイアウトだけ直す。
3. テーマ以外にも投稿したくなる場合: v0.9で `自分の投稿` を検討する。
4. 人間がテーマを作りたくなる場合: v0.9で hostテーマを検討する。
