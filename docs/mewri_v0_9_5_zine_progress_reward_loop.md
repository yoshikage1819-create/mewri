# mewri v0.9.5: zine progress / reward loop refinement

## what changed
- Active ZINEカードに進捗指標を追加
  - 投稿数（現在/目標）
  - サイクル終了までの残り時間
  - 完成までの割合（%）
- 投稿フォーム付近に補助コピーを追加
  - 「今日の投稿がこの期間の小さなZINEにまとまる」ことを明示
- 投稿成功時の貢献メッセージを追加
  - `あなたの投稿がZINEに追加されました` と更新済み進捗を表示
- 投稿カードに所属情報を追加
  - どのZINE/テーマの投稿かを明示
- 生成済みZINEプレビューを軽く強化
  - カバー風見出し
  - ページ画像の紙面感（枠・余白・影）
  - 締めの一文を追加
- セクションIAは維持
  1. Participating ZINE
  2. このZINEの中身
  3. フォロー中ユーザーの投稿
  4. 発見と回遊
- 未実装領域は明示
  - フォロー、公開探索、通知などは「未実装/将来機能」として明記

## why this is still within MVP scope
- 既存の主ループ（Theme -> Post -> In-progress ZINE -> Generated ZINE）の可視化と文言改善に限定。
- 既存データ構造・投稿導線・ZINE生成条件は維持。
- 実装は主に表示ロジックとUI文言、軽微なスタイル調整のみ。

## intentionally not added
- 認証
- 実フォロー機能
- コメント / いいね
- 通知
- 公開ディスカバリー
- 共有DBロジック
- 画像アップロード保存

## what should be tested next
- 進捗表示
  - 投稿前後で「投稿数」「完成まで%」が更新される
  - サイクル終了日までの残り時間表示が不自然でない
- 投稿導線
  - 投稿後メッセージが表示され、進捗値が最新化される
- フィード文脈
  - 各投稿カードにZINE/テーマ情報が表示される
- ZINEプレビュー
  - 生成済み時にカバー・ページ・締め文が表示される
- IAと未実装表示
  - 3/4セクションがプレースホルダーとして明示される
- レスポンシブ安定性
  - モバイル/デスクトップで大きなレイアウト崩れがない
