# ローカルデモ確認ガイド

更新日: 2026-06-16

このガイドは、Mewri のローカルデモを安全に触って、感想を返すためのものです。
技術の確認ではなく、体験の確認をします。

## ローカルデモとは

ローカルデモは、開発中の Mewri をブラウザで試すための画面です。
本番サービスではありません。

このデモで確認する流れは次の4つです。

1. 今日のテーマを見る。
2. 写真と短い言葉を投稿する。
3. 投稿が ZINE の一部になる感じを見る。
4. もう一度見たいか、誰かに見せたいかを考える。

## ローカルデモではないもの

次のものではありません。

- 本番の Mewri
- 本物の参加者データ
- ログイン機能
- クラウド保存
- 友達との本番共有
- Supabase / database / Storage の検証画面
- セキュリティ判断のための画面

## 触ってよいこと

- 画面を上から順番に見る。
- 今日のテーマを読む。
- 練習用の写真を選ぶ。
- 短いキャプションを書く。
- 投稿から ZINE になる流れを見る。
- わかりにくいところ、冷たいところ、よかったところをメモする。

## 入力しないもの

安全のため、次は入力しないでください。

- 本物のパスワード
- API key
- token
- magic link
- secret URL
- 本番や staging のログイン情報
- 自分や他人の住所、電話番号、メールアドレスなどの個人情報
- 非公開の参加者情報

迷ったら、そこで止まってください。
自分で判断しなくて大丈夫です。

## 見るポイント

画面を触りながら、次を見てください。

- 最初に、何をする場所か伝わったか。
- 今日のテーマで、写真を投稿したくなったか。
- 投稿ボタンや流れで迷わなかったか。
- ZINE を見て、読み返したい感じがあったか。
- 友達に見せたい、または誘いたい感じがあったか。
- 画面や言葉が冷たくないか。
- SaaSっぽい、管理画面っぽい、説明っぽい感じが強くないか。

## 感想テンプレート

検証後、次をコピーして答えてください。

```text
見た日:
使った端末: PC / スマホ / タブレット

1. これは何をする場所だと思った？

2. 最初に迷ったところは？

3. 今日のテーマを見て、写真を投稿したくなった？

4. 投稿から ZINE になる流れはどう感じた？

5. もう一度開きたいと思った？
   その理由は？

6. 誰かに見せたい、誘いたいと思った？

7. 冷たく感じた言葉や画面は？

8. あたたかく感じた言葉や画面は？

9. Mewri らしくて残したいところは？

10. 次に1つだけ直すならどこ？
```

## オーナーが記録すること

友人の言葉だけでなく、行動も見ます。

```text
説明なしで理解できたか:
投稿まで進んだか:
ZINE まで見たか:
強く反応した瞬間:
途中で止まった場所:
もう一度使いたいと言ったか:
友達に見せたいと言ったか:
```

## 成功の目安

3人から5人に試してもらい、次が起きたら前進です。

- 2人以上が「触ってみたい」と言う。
- 1人以上が投稿から ZINE まで進む。
- 1人以上が Mewri を自分の言葉で説明できる。
- 1人以上が ZINE を誰かに見せたい、またはもう一度見たいと言う。

## 技術的な判断はしない

次の判断は、友人やオーナーだけでは進めません。
Codex に戻して確認します。

- login / auth
- database
- Supabase
- Storage
- RLS / policy
- migration
- deploy
- production
- shared mode
- secrets / env

ローカルデモでは、体験の温度と言葉を見ます。
技術の安全確認は別の作業として扱います。
