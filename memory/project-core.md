# Project Core

Mewri is a group-first photo product. It is not a general public photo feed.

The core loop is:

```text
Theme -> Post -> ZINE contribution -> generated ZINE
```

The product should keep invited small groups and shared ZINE creation at the
center. Public discovery, follows, likes, and broad social graph features are
not the current bet.

AI is assistive. It may help with themes, titles, layouts, summaries, and
presentation, but it is not the source of participant meaning. The value comes
from people contributing their photos and presence to a shared ZINE.
